关于全栈AI对话助手

全栈AI对话助手 v3.0

多模型智能对话平台

功能特点

  • 支持多种AI模型API (OpenAI, DeepSeek, Claude等)
  • 多模态文件上传 (图片、视频、音频、文档)
  • Markdown格式渲染 (表格、代码块、数学公式)
  • 完整的消息操作 (复制、重新生成、编辑)
  • 响应式设计，支持深色/浅色主题
  • 所有数据本地存储，保护隐私安全

技术栈

HTML5 CSS3 JavaScript LocalStorage Fetch API Web Workers
